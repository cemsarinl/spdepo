# @saripartners Instagram yönetimi

| Dosya / klasör | İçerik |
|---|---|
| `AKTIVASYON.md` | Hesabı Claude'a bağlama rehberi (önce bunu okuyun) |
| `rehber/uyum-kurallari.md` | Avukatlık reklam yasağına uygun paylaşım kuralları |
| `rehber/seri-plani.md` | Görsel kimlik, seriler ve 4 haftalık yayın planı |
| `rehber/haftalik-akis.md` | Haftalık taslak, onay ve yayın akışı |
| `takvim/ozel-gunler.md` | Yıllık özel gün ve haftalar takvimi, yayın ritmi |
| `marka.json`, `marka/` | Renkler, yazı tipleri, logo (saripartners.com ile uyumlu) |
| `render/` | Görsel (`render.js`) ve Reels (`make_reel.py`) üreticileri |
| `yayinla.py` | Onaylı içeriği Instagram'da yayınlar |
| `icerik/` | Gönderi klasörleri: `spec.json`, `caption.txt`, `meta.json`, `gorseller/`, `reel.mp4` |
